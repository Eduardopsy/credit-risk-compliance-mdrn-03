## 1. Overview and Responsibilities

### 1.1 Scope

This frente owns all asynchronous processing components:

- **Credit Analysis Worker** (`CreditRisk.CreditAnalysis.Worker`): Consumes `CreditProposalCreatedEvent`, orchestrates bureau queries, runs the scoring engine, publishes evaluation results.
- **Compliance Worker** (`CreditRisk.Compliance.Worker`): Consumes `TransactionReceivedCommand`, applies AML/CFT rules, creates alerts, publishes events to Operations Panel.
- **MassTransit/RabbitMQ topology**: All exchanges, queues, DLQs, retry policies, circuit breakers.
- **Bureau HTTP client**: Named `HttpClient` with Polly resilience (retry + circuit breaker), 10s timeout.
- **PEP/Sanctions screening**: Redis-cached external API calls with 24h TTL.
- **Outbox pattern**: Guaranteed message delivery for domain events.
- **Operations Hub consumers**: MassTransit consumers in `CreditRisk.Operations.Server` that push events to SignalR groups.

### 1.2 Boundaries

**Owns:** `CreditRisk.CreditAnalysis.Worker`, `CreditRisk.Compliance.Worker`, MassTransit configuration in all services, Outbox infrastructure.

**Does NOT own:** API endpoint definitions (SPEC-02), domain business logic (SPEC-02), frontend (SPEC-05), Docker/CI (SPEC-07).

**Depends on (from SPEC-01):**
- `CreditRisk.Shared.Contracts`: All message contracts consumed and published by workers
- `CreditRisk.Shared.Kernel`: Domain abstractions

**Depends on (from SPEC-02):**
- `CreditRisk.CreditAnalysis.Domain` and `Application`: Domain entities and services
- `CreditRisk.Compliance.Domain` and `Application`: Domain entities and services

### 4.2 MassTransit Configuration (Standard for All Services)

```csharp
// Standard MassTransit registration — used in all API and Worker Program.cs files
// File: src/modules/credit-analysis/CreditRisk.CreditAnalysis.Worker/Program.cs
using CreditRisk.CreditAnalysis.Worker.Consumers;
using CreditRisk.Shared.Observability;
using MassTransit;

HostApplicationBuilder builder = Host.CreateApplicationBuilder(args);

// Observability
builder.Services.AddCreditRiskObservability(builder.Configuration, serviceName: "credit-analysis-worker");

// MassTransit with RabbitMQ
builder.Services.AddMassTransit(x =>
{
    // Explicit consumer registration (AOT-compatible — no assembly scanning)
    x.AddConsumer<CreditProposalCreatedEventConsumer>();
    x.AddConsumer<BureauQueryRequestedCommandConsumer>();

    x.UsingRabbitMq((context, cfg) =>
    {
        cfg.Host(
            builder.Configuration["RabbitMQ__Host"]!,
            builder.Configuration["RabbitMQ__VHost"] ?? "crcl",
            h =>
            {
                h.Username(builder.Configuration["RabbitMQ__Username"]!);
                h.Password(builder.Configuration["RabbitMQ__Password"]!);
            });

        // Global retry: 3 retries with exponential backoff (1s, 6s, 31s)
        cfg.UseMessageRetry(r => r.Exponential(
            retryLimit: 3,
            minInterval: TimeSpan.FromSeconds(1),
            maxInterval: TimeSpan.FromSeconds(30),
            intervalDelta: TimeSpan.FromSeconds(5)));

        // Global circuit breaker
        cfg.UseCircuitBreaker(cb =>
        {
            cb.TrackingPeriod = TimeSpan.FromMinutes(1);
            cb.TripThreshold = 15;      // Trip if 15% of messages fail
            cb.ActiveThreshold = 10;    // Minimum 10 messages before tripping
            cb.ResetInterval = TimeSpan.FromMinutes(5);
        });

        // OpenTelemetry trace propagation
        cfg.PropagateActivityContext = true;

        // Auto-configure endpoints from registered consumers
        cfg.ConfigureEndpoints(context);
    });
});

// Infrastructure services
builder.Services.AddCreditAnalysisInfrastructure(builder.Configuration);

// Bureau HTTP client with resilience
builder.Services.AddHttpClient("bureau-api", client =>
{
    client.BaseAddress = new Uri(builder.Configuration["Bureau__BaseUrl"]!);
    client.Timeout = TimeSpan.FromSeconds(10);
    client.DefaultRequestHeaders.Add("X-Api-Key", builder.Configuration["Bureau__ApiKey"]!);
})
.AddStandardResilienceHandler(options =>
{
    options.Retry.MaxRetryAttempts = 3;
    options.Retry.Delay = TimeSpan.FromSeconds(1);
    options.Retry.BackoffType = Polly.DelayBackoffType.Exponential;
    options.CircuitBreaker.SamplingDuration = TimeSpan.FromMinutes(1);
    options.CircuitBreaker.FailureRatio = 0.5;
    options.CircuitBreaker.MinimumThroughput = 5;
    options.CircuitBreaker.BreakDuration = TimeSpan.FromMinutes(5);
    options.TotalRequestTimeout.Timeout = TimeSpan.FromSeconds(15);
});

IHost host = builder.Build();
await host.RunAsync();
```

### 4.3 Credit Analysis Worker — Consumers

```csharp
// File: src/modules/credit-analysis/CreditRisk.CreditAnalysis.Worker/Consumers/CreditProposalCreatedEventConsumer.cs
using CreditRisk.CreditAnalysis.Application.Ports;
using CreditRisk.CreditAnalysis.Domain.Repositories;
using CreditRisk.CreditAnalysis.Domain.Services;
using CreditRisk.Shared.Contracts.CreditAnalysis.Events;
using MassTransit;

namespace CreditRisk.CreditAnalysis.Worker.Consumers;

/// <summary>
/// Consumes CreditProposalCreatedEvent from RabbitMQ.
/// Orchestrates: bureau query → scoring → evaluation → publish result.
/// Queue: credit-worker_credit-proposal-created-event
/// DLQ:   credit-worker_credit-proposal-created-event_error
/// </summary>
public sealed class CreditProposalCreatedEventConsumer(
    ICreditProposalRepository proposalRepository,
    ICustomerRepository customerRepository,
    ICreditScoringEngine scoringEngine,
    IBureauQueryService bureauQueryService,
    IUnitOfWork unitOfWork,
    IPublishEndpoint publishEndpoint,
    ILogger<CreditProposalCreatedEventConsumer> logger)
    : IConsumer<CreditProposalCreatedEvent>
{
    public async Task Consume(ConsumeContext<CreditProposalCreatedEvent> context)
    {
        var message = context.Message;
        using var activity = WorkerActivitySource.StartActivity("ProcessCreditProposal");
        activity?.SetTag("proposal.id", message.ProposalId.ToString());
        activity?.SetTag("customer.id", message.CustomerId.ToString());

        logger.LogInformation(
            "Processing credit proposal {ProposalId} for customer {CustomerId}",
            message.ProposalId, message.CustomerId);

        var proposal = await proposalRepository.GetByIdAsync(message.ProposalId, context.CancellationToken)
            .ConfigureAwait(false);

        if (proposal is null)
        {
            logger.LogError("Proposal {ProposalId} not found. Skipping.", message.ProposalId);
            return;
        }

        var customer = await customerRepository.GetByIdAsync(message.CustomerId, context.CancellationToken)
            .ConfigureAwait(false);

        if (customer is null)
        {
            logger.LogError("Customer {CustomerId} not found. Skipping.", message.CustomerId);
            return;
        }

        // Query bureau (with Polly resilience via HttpClient)
        var bureauResult = await bureauQueryService.QueryAsync(
            customer.Document.Value,
            customer.DocumentType,
            context.CancellationToken).ConfigureAwait(false);

        // Run scoring engine
        var scoringResult = scoringEngine.Evaluate(
            bureauScore: bureauResult.Score,
            monthlyIncome: customer.MonthlyIncome.Amount,
            totalMonthlyDebt: bureauResult.TotalMonthlyDebt,
            requestedLimit: proposal.RequestedLimit.Amount);

        // Apply evaluation to aggregate
        proposal.ApplyEvaluation(
            scoringResult.Rating,
            CreditRisk.Shared.Kernel.ValueObjects.MoneyAmount.Create(scoringResult.ApprovedLimit),
            scoringResult.RequiresManualReview);

        await proposalRepository.UpdateAsync(proposal, context.CancellationToken).ConfigureAwait(false);
        await unitOfWork.CommitAsync(context.CancellationToken).ConfigureAwait(false);

        // Publish evaluation result
        await publishEndpoint.Publish(new CreditProposalEvaluatedEvent
        {
            ProposalId = proposal.Id,
            CustomerId = proposal.CustomerId,
            RiskRating = scoringResult.Rating.ToString(),
            ApprovedLimit = scoringResult.ApprovedLimit,
            EvaluatedAt = DateTimeOffset.UtcNow,
            EvaluatedBy = "AUTO",
            RequiresManualReview = scoringResult.RequiresManualReview,
            CorrelationId = message.CorrelationId
        }, context.CancellationToken).ConfigureAwait(false);

        activity?.SetTag("risk.rating", scoringResult.Rating.ToString());
        activity?.SetTag("requires.review", scoringResult.RequiresManualReview.ToString());

        logger.LogInformation(
            "Proposal {ProposalId} evaluated: Rating={Rating}, RequiresReview={RequiresReview}",
            proposal.Id, scoringResult.Rating, scoringResult.RequiresManualReview);
    }
}
```

### 4.4 Compliance Worker — Consumers

```csharp
// File: src/modules/compliance/CreditRisk.Compliance.Worker/Consumers/TransactionReceivedCommandConsumer.cs
using CreditRisk.Compliance.Application.Ports;
using CreditRisk.Compliance.Domain.Repositories;
using CreditRisk.Compliance.Domain.Services;
using CreditRisk.Shared.Contracts.Compliance.Commands;
using CreditRisk.Shared.Contracts.Compliance.Events;
using MassTransit;

namespace CreditRisk.Compliance.Worker.Consumers;

/// <summary>
/// Consumes TransactionReceivedCommand from RabbitMQ.
/// Applies AML/CFT rules engine. Creates alerts for flagged transactions.
/// Queue: compliance-worker_transaction-received-command
/// DLQ:   compliance-worker_transaction-received-command_error
/// </summary>
public sealed class TransactionReceivedCommandConsumer(
    ITransactionRepository transactionRepository,
    IAmlAlertRepository alertRepository,
    IAmlRulesEngine amlRulesEngine,
    IPepScreeningService pepScreeningService,
    IComplianceUnitOfWork unitOfWork,
    IPublishEndpoint publishEndpoint,
    ILogger<TransactionReceivedCommandConsumer> logger)
    : IConsumer<TransactionReceivedCommand>
{
    public async Task Consume(ConsumeContext<TransactionReceivedCommand> context)
    {
        var message = context.Message;

        // Idempotency check — skip if already processed
        var existing = await transactionRepository.GetByIdAsync(message.TransactionId, context.CancellationToken)
            .ConfigureAwait(false);

        if (existing is not null)
        {
            logger.LogDebug("Transaction {TransactionId} already processed. Skipping.", message.TransactionId);
            return;
        }

        // PEP screening (Redis-cached, 24h TTL)
        bool isPep = await pepScreeningService.IsPersonPoliticallyExposedAsync(
            message.CustomerDocument, context.CancellationToken).ConfigureAwait(false);

        // Create transaction entity
        var transaction = Transaction.Create(
            id: message.TransactionId,
            customerId: message.CustomerId,
            customerDocument: message.CustomerDocument,
            amount: CreditRisk.Shared.Kernel.ValueObjects.MoneyAmount.Create(message.Amount),
            transactionType: message.TransactionType,
            channel: message.Channel,
            transactionDate: message.TransactionDate,
            correlationId: message.CorrelationId);

        await transactionRepository.AddAsync(transaction, context.CancellationToken).ConfigureAwait(false);

        // Apply AML rules
        var flags = await amlRulesEngine.EvaluateAsync(transaction, context.CancellationToken)
            .ConfigureAwait(false);

        if (isPep)
        {
            flags = [.. flags, new AmlFlag("PepMatch", "Critical", "Customer is a Politically Exposed Person")];
        }

        if (flags.Count > 0)
        {
            transaction.Flag(flags.Select(f => f.RuleType).ToArray());

            foreach (var flag in flags)
            {
                var alert = AmlAlert.Create(
                    transactionId: transaction.Id,
                    customerId: transaction.CustomerId,
                    alertType: flag.RuleType,
                    severity: flag.Severity,
                    transactionAmount: transaction.Amount.Amount,
                    correlationId: message.CorrelationId);

                await alertRepository.AddAsync(alert, context.CancellationToken).ConfigureAwait(false);

                await publishEndpoint.Publish(new AmlAlertCreatedEvent
                {
                    AlertId = alert.Id,
                    TransactionId = transaction.Id,
                    CustomerId = transaction.CustomerId,
                    AlertType = flag.RuleType,
                    Severity = flag.Severity,
                    TransactionAmount = transaction.Amount.Amount,
                    CreatedAt = DateTimeOffset.UtcNow,
                    CorrelationId = message.CorrelationId
                }, context.CancellationToken).ConfigureAwait(false);
            }

            await publishEndpoint.Publish(new TransactionFlaggedEvent
            {
                TransactionId = transaction.Id,
                CustomerId = transaction.CustomerId,
                FlagReason = string.Join(", ", flags.Select(f => f.RuleType)),
                TriggeredRules = flags.Select(f => f.RuleType).ToArray(),
                FlaggedAt = DateTimeOffset.UtcNow,
                CorrelationId = message.CorrelationId
            }, context.CancellationToken).ConfigureAwait(false);
        }

        await unitOfWork.CommitAsync(context.CancellationToken).ConfigureAwait(false);

        logger.LogInformation(
            "Transaction {TransactionId} processed. Flags={FlagCount}",
            transaction.Id, flags.Count);
    }
}
```

```csharp
using Microsoft.AspNetCore.Authorization;

namespace CreditRisk.Operations.Server.Hubs;

/// <summary>
/// SignalR hub for real-time operations dashboard updates.
/// Clients join role-based groups on connection.
/// Requires authentication — JWT validated by Keycloak.
/// </summary>
[Authorize]
public sealed class OperationsHub : Hub
{
    /// <summary>
    /// Adds the connected client to the role-based group.
    /// Called by the Blazor client on connection.
    /// </summary>
    public async Task JoinRoleGroup(string role)
    {
        string allowedRole = role switch
        {
            "desk-operator" => "role:desk-operator",
            "compliance-analyst" => "role:compliance-analyst",
            "administrator" => "role:administrator",
            _ => throw new HubException($"Unknown role: {role}")
        };

        await Groups.AddToGroupAsync(Context.ConnectionId, allowedRole).ConfigureAwait(false);
    }

    /// <summary>Removes the client from all role groups on disconnect.</summary>
    public override async Task OnDisconnectedAsync(Exception? exception)
    {
        await Groups.RemoveFromGroupAsync(Context.ConnectionId, "role:desk-operator").ConfigureAwait(false);
        await Groups.RemoveFromGroupAsync(Context.ConnectionId, "role:compliance-analyst").ConfigureAwait(false);
        await Groups.RemoveFromGroupAsync(Context.ConnectionId, "role:administrator").ConfigureAwait(false);
        await base.OnDisconnectedAsync(exception).ConfigureAwait(false);
    }
}
```

### 4.6 Outbox Pattern

```csharp
// File: src/shared/CreditRisk.Shared.Kernel/Outbox/OutboxMessage.cs
using CreditRisk.Shared.Kernel.Domain;

namespace CreditRisk.Shared.Kernel.Outbox;

/// <summary>
/// Represents a message stored in the outbox table for guaranteed delivery.
/// Messages are written atomically with the business transaction and processed by OutboxProcessor.
/// </summary>
public sealed class OutboxMessage : Entity
{
    public string MessageType { get; private init; } = string.Empty;
    public string Payload { get; private init; } = string.Empty;
    public DateTimeOffset ScheduledAt { get; private init; }
    public DateTimeOffset? ProcessedAt { get; private set; }
    public int RetryCount { get; private set; }
    public string? Error { get; private set; }

    private OutboxMessage() : base() { }

    public static OutboxMessage Create(string messageType, string payload)
    {
        Guard.AgainstNullOrWhiteSpace(messageType, nameof(messageType));
        Guard.AgainstNullOrWhiteSpace(payload, nameof(payload));

        return new OutboxMessage
        {
            MessageType = messageType,
            Payload = payload,
            ScheduledAt = DateTimeOffset.UtcNow
        };
    }

    public void MarkProcessed() => ProcessedAt = DateTimeOffset.UtcNow;

    public void MarkFailed(string error)
    {
        Error = error;
        RetryCount++;
    }
}
```

```csharp
// File: src/modules/credit-analysis/CreditRisk.CreditAnalysis.Infrastructure/Outbox/OutboxProcessor.cs
using CreditRisk.Shared.Kernel.Outbox;
using MassTransit;
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Hosting;
using System.Text.Json;

namespace CreditRisk.CreditAnalysis.Infrastructure.Outbox;

/// <summary>
/// Background service that polls the outbox table and publishes pending messages via MassTransit.
/// Runs every 5 seconds. Processes up to 100 messages per batch.
/// Marks messages as processed after successful publish.
/// </summary>
public sealed class OutboxProcessor(
    IServiceScopeFactory scopeFactory,
    ILogger<OutboxProcessor> logger) : BackgroundService
{
    private static readonly TimeSpan PollingInterval = TimeSpan.FromSeconds(5);
    private const int BatchSize = 100;
    private const int MaxRetries = 5;

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        logger.LogInformation("OutboxProcessor started.");

        while (!stoppingToken.IsCancellationRequested)
        {
            try
            {
                await ProcessBatchAsync(stoppingToken).ConfigureAwait(false);
            }
            catch (Exception ex) when (!stoppingToken.IsCancellationRequested)
            {
                logger.LogError(ex, "OutboxProcessor batch failed. Retrying in {Interval}s.", PollingInterval.TotalSeconds);
            }

            await Task.Delay(PollingInterval, stoppingToken).ConfigureAwait(false);
        }

        logger.LogInformation("OutboxProcessor stopped.");
    }

    private async Task ProcessBatchAsync(CancellationToken cancellationToken)
    {
        await using var scope = scopeFactory.CreateAsyncScope();
        var dbContext = scope.ServiceProvider.GetRequiredService<CreditAnalysisDbContext>();
        var publishEndpoint = scope.ServiceProvider.GetRequiredService<IPublishEndpoint>();

        var pendingMessages = await dbContext.OutboxMessages
            .Where(m => m.ProcessedAt == null && m.RetryCount < MaxRetries)
            .OrderBy(m => m.ScheduledAt)
            .Take(BatchSize)
            .ToListAsync(cancellationToken)
            .ConfigureAwait(false);

        foreach (var message in pendingMessages)
        {
            try
            {
                var messageType = Type.GetType(message.MessageType);
                if (messageType is null)
                {
                    logger.LogError("Unknown message type: {MessageType}", message.MessageType);
                    message.MarkFailed($"Unknown type: {message.MessageType}");
                    continue;
                }

                var payload = JsonSerializer.Deserialize(message.Payload, messageType);
                if (payload is null)
                {
                    message.MarkFailed("Deserialization returned null.");
                    continue;
                }

                await publishEndpoint.Publish(payload, messageType, cancellationToken).ConfigureAwait(false);
                message.MarkProcessed();

                logger.LogDebug("Outbox message {MessageId} published.", message.Id);
            }
            catch (Exception ex)
            {
                logger.LogWarning(ex, "Failed to publish outbox message {MessageId}.", message.Id);
                message.MarkFailed(ex.Message);
            }
        }

        await dbContext.SaveChangesAsync(cancellationToken).ConfigureAwait(false);
    }
}
```

### 4.7 Bureau HTTP Client

```csharp
// File: src/modules/credit-analysis/CreditRisk.CreditAnalysis.Worker/Services/BureauHttpClient.cs
using CreditRisk.CreditAnalysis.Application.Ports;
using System.Net.Http.Json;
using System.Text.Json.Serialization;

namespace CreditRisk.CreditAnalysis.Worker.Services;

/// <summary>
/// HTTP client for external credit bureau queries.
/// Uses named HttpClient "bureau-api" configured with Polly resilience in Program.cs.
/// Timeout: 10 seconds. Retry: 3x exponential. Circuit breaker: 50% failure rate.
/// Falls back to cached result if available; returns degraded result if cache miss.
/// </summary>
internal sealed class BureauHttpClient(
    IHttpClientFactory httpClientFactory,
    IStackExchange.Redis.IConnectionMultiplexer redis,
    ILogger<BureauHttpClient> logger) : IBureauQueryService
{
    private static readonly TimeSpan CacheTtl = TimeSpan.FromHours(24);
    private const string CacheKeyPrefix = "bureau:result:";

    public async Task<BureauQueryResult> QueryAsync(
        string document,
        string documentType,
        CancellationToken cancellationToken = default)
    {
        string cacheKey = $"{CacheKeyPrefix}{document}";
        var db = redis.GetDatabase();

        // Check Redis cache first
        string? cached = await db.StringGetAsync(cacheKey).ConfigureAwait(false);
        if (cached is not null)
        {
            logger.LogDebug("Bureau cache hit for document hash.");
            return System.Text.Json.JsonSerializer.Deserialize<BureauQueryResult>(cached)!;
        }

        try
        {
            var client = httpClientFactory.CreateClient("bureau-api");
            var response = await client.PostAsJsonAsync(
                "/query",
                new { Document = document, DocumentType = documentType },
                cancellationToken).ConfigureAwait(false);

            response.EnsureSuccessStatusCode();

            var result = await response.Content.ReadFromJsonAsync<BureauQueryResult>(
                cancellationToken: cancellationToken).ConfigureAwait(false)
                ?? throw new InvalidOperationException("Bureau API returned null response.");

            // Cache the result
            string serialized = System.Text.Json.JsonSerializer.Serialize(result);
            await db.StringSetAsync(cacheKey, serialized, CacheTtl).ConfigureAwait(false);

            return result;
        }
        catch (HttpRequestException ex)
        {
            logger.LogWarning(ex, "Bureau API unavailable. Returning degraded result.");
            // Degraded mode: return minimum score to trigger manual review
            return new BureauQueryResult(Score: 0, TotalMonthlyDebt: 0m, IsDegraded: true);
        }
    }
}

/// <summary>Result from the credit bureau query.</summary>
public sealed record BureauQueryResult(
    int Score,
    decimal TotalMonthlyDebt,
    bool IsDegraded = false);
```

## 5. Business Rules and Invariants

### 5.1 Message Processing Rules

1. All consumers must be idempotent — processing the same message twice must produce the same result.
2. Consumers must never throw unhandled exceptions — MassTransit retry policy handles transient failures.
3. After `MaxRetries` (3) attempts, messages are moved to the DLQ automatically by MassTransit.
4. DLQ messages trigger the `DeadLetterQueueMessages` Prometheus alert (see SPEC-07).
5. Consumers must complete within 30 seconds — MassTransit consumer timeout.

### 5.2 Bureau Query Rules

1. Bureau queries are cached in Redis for 24 hours using the customer document as the cache key.
2. If the bureau API is unavailable (circuit breaker open), return a degraded result (score=0) to trigger manual review — never block the proposal pipeline.
3. Bureau consent must be recorded before any query is made (enforced in Application layer).
4. Bureau API timeout: 10 seconds maximum.
5. Polly retry: 3 attempts with exponential backoff (1s, 2s, 4s).

### 5.3 PEP Screening Rules

1. PEP screening results are cached in Redis for 24 hours.
2. A PEP match always creates a `Critical` severity AML alert.
3. A PEP match blocks the transaction immediately — no further rule evaluation needed.
4. PEP list is sourced from the external API defined in `PepScreening__BaseUrl`.

### 5.4 Outbox Rules

1. Outbox messages are written in the same database transaction as the business operation.
2. `OutboxProcessor` polls every 5 seconds and processes up to 100 messages per batch.
3. Messages that fail after `MaxRetries` (5) are marked with an error and not retried.
4. Failed outbox messages trigger a `Critical` alert in Grafana.
5. Outbox messages are never deleted — they are marked as processed for audit purposes.

### 5.5 SignalR Push Rules

1. AML alerts are pushed only to `role:compliance-analyst` and `role:administrator` groups.
2. Credit limit approvals are pushed to the specific desk operator's connection group.
3. If no clients are connected in a group, the push is silently dropped (fire-and-forget).
4. SignalR push failures must not cause the MassTransit consumer to fail.

## 6. Design Decisions and Architectural Patterns

### 6.1 MassTransit over Raw RabbitMQ

**Decision:** All messaging uses MassTransit 8.x. Direct RabbitMQ client (`RabbitMQ.Client`) is forbidden.

**Rationale:** MassTransit provides retry policies, circuit breakers, DLQ management, OpenTelemetry propagation, and consumer lifecycle management out of the box. Raw RabbitMQ requires reimplementing all of this.

### 6.2 Explicit Consumer Registration (AOT Compatibility)

**Decision:** Consumers are registered explicitly with `x.AddConsumer<TConsumer>()`, not via `x.AddConsumers(Assembly)`.

**Rationale:** Assembly scanning uses reflection which is incompatible with Native AOT trimming.

### 6.3 Outbox Pattern for Guaranteed Delivery

**Decision:** Domain events are stored in an outbox table within the same database transaction, then dispatched asynchronously by `OutboxProcessor`.

**Rationale:** Without the outbox, a crash between `SaveChanges` and `Publish` would result in a committed database state with no corresponding message — a data inconsistency. The outbox guarantees at-least-once delivery.

### 6.4 Polly Resilience for Bureau HTTP

**Decision:** Bureau HTTP client uses `AddStandardResilienceHandler` from `Microsoft.Extensions.Http.Resilience`.

**Rationale:** Provides retry, circuit breaker, timeout, and hedging in a single, well-tested configuration. The degraded fallback (score=0 → manual review) ensures the proposal pipeline never blocks on bureau unavailability.

## 9. Acceptance Criteria and Definition of Done

### 9.1 MassTransit Configuration

- [ ] All consumers registered explicitly (no assembly scanning)
- [ ] Global retry policy: 3 retries, exponential backoff (1s, 6s, 31s)
- [ ] Global circuit breaker: 15% trip threshold, 10 message minimum, 5-minute reset
- [ ] `PropagateActivityContext = true` for OpenTelemetry trace propagation
- [ ] All queues have corresponding DLQs (auto-generated by MassTransit `_error` suffix)
- [ ] `DeadLetterQueueMessages` Prometheus alert fires when DLQ has messages

### 9.2 Credit Analysis Worker

- [ ] `CreditProposalCreatedEventConsumer` processes proposals end-to-end
- [ ] Bureau query results cached in Redis for 24 hours
- [ ] Bureau unavailability returns degraded result (score=0) — never blocks pipeline
- [ ] `CreditProposalEvaluatedEvent` published after every evaluation
- [ ] Consumer is idempotent — duplicate messages produce same result
- [ ] Worker compiles with `PublishAot=true` without ILC warnings

### 9.3 Compliance Worker

- [ ] `TransactionReceivedCommandConsumer` processes transactions end-to-end
- [ ] Idempotency check prevents duplicate transaction processing
- [ ] All 5 AML rules evaluated in order
- [ ] PEP match creates `Critical` severity alert
- [ ] `AmlAlertCreatedEvent` published for each flag
- [ ] `TransactionFlaggedEvent` published when any rule triggers

### 9.4 Operations Hub

- [ ] `OperationsHub` requires JWT authentication
- [ ] `JoinRoleGroup` adds client to correct role group
- [ ] `AmlAlertCreatedEventConsumer` pushes to `role:compliance-analyst` and `role:administrator`
- [ ] SignalR push failure does not cause consumer to fail or retry

### 9.5 Outbox

- [ ] Outbox messages written atomically with business transaction
- [ ] `OutboxProcessor` polls every 5 seconds
- [ ] Messages marked as processed after successful publish
- [ ] Messages with `RetryCount >= 5` are skipped
- [ ] Failed messages retain error message for debugging
